# Contributing to secure-notify

Thank you for helping. The full contribution guide is in
[docs/community/contributing.md](docs/community/contributing.md).

Quick start:

1. Read [AGENTS.md](AGENTS.md): it contains the working rules for everyone, human or agent.
2. Find the doc for the area you want to change in [docs/README.md](docs/README.md).
3. Adding a feed or a taxonomy entry needs no code: one TOML file and a pull request.
4. Design changes start as a docs pull request.
5. Branch from `develop` and target it with your pull request (gitflow, see
   [docs/engineering/git-workflow.md](docs/engineering/git-workflow.md)). Verify the changed flow
   locally before marking the pull request ready for review (see
   [docs/engineering/workflow.md](docs/engineering/workflow.md)).

Working with AI assistants and coding agents is welcome. They start at [AGENTS.md](AGENTS.md) and
load only the skills they need from the [skills index](.agents/skills/README.md).

By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
